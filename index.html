Open tools for building software with AI agents.

Three projects that work together, all free and open source. If any of them ever makes money, it goes back to the people who build it.

The projects

  • Irie

    Runs your AI coding agents side by side, in one calm view. Each agent works in its own terminal and its own copy of the repository, and you see at a glance which ones need you.

    • Website
    • Code
    • Releases

  • Riddim

    A small language for code that agents write and people review. It reads like a small Rust, compiles to readable Go, and stops what agents most often get wrong before it reaches you.

    • Website
    • Code
    • Releases

  • Steak

    A contribution ledger for open source. If a project ever makes money, Steak pays it back to the people who built it, by the value of their work.

    • Website
    • Code
    • Releases

How they fit together

  • Irie runs the agents. Many at once, each on its own task, all in one view.
  • Riddim checks their code. Exact diagnostics in milliseconds, so a reviewer only sees code that compiles.
  • Steak pays the people. A public record of who built what, so any money goes back to them.

Free, and paid back

Each project keeps a public record of who built it, and of how money would be shared if any ever arrives: Irie's, Riddim's and Steak's. The founder started with no Steak in any of them and earns it the same way as everyone else.

Irie and Riddim are free under the Apache 2.0 license, and Steak under the MIT license. Each is built from public documentation and lists every source in its PROVENANCE.md.
